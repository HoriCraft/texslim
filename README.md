# TexSlim（テックスリム）

VRChat アバターのテクスチャを **非破壊で軽くする** Unity エディタ拡張です。

ダウンロードサイズとテクスチャメモリ（VRAM）を、日常的に使える範囲まで減らすことを目的にしています。
Excellent ランクを狙うためのものではなく、「重すぎるアバターを普通に使えるところまで落とす」ためのツールです。

## 特徴

**元の画像ファイルには一切手を触れません。**
変更するのはテクスチャのインポート設定（`.meta`）だけです。`.png` などの画像本体はそのまま残るので、
戻したときの画質は完全に元どおりになります。

**いつでも戻せます。**
圧縮する前の設定を `ProjectSettings/TexSlim.json` に記録します。
記録は初回だけ保存され、あとから上書きされません。何度圧縮し直しても、常に「本当の元の状態」へ戻せます。
戻す操作は3種類あります。

| 範囲 | 場所 |
|---|---|
| テクスチャ1枚だけ | 詳細タブ … 各行の `↩ 戻す` |
| このアバター分 | かんたん／詳細タブ … `↩ 元に戻す` |
| プロジェクト全体 | 設定タブ … `↩ 圧縮したテクスチャをすべて元に戻す` |

記録はプロジェクト全体で1つなので、**別のシーンから開いても元の設定を辿れます。**

**顔・髪は最初から守られます。**
名前に `face` `eye` `顔` `瞳` などを含むテクスチャは、初期状態で圧縮対象から自動的に外れます。
髪（`hair` `髪` `ヘア` など）も同様です。ほかに守りたいものは設定タブで足せます。

**日本語／英語を切り替えられます。**
ヘッダー右上のボタンでいつでも切り替わります。

## 使い方

1. Hierarchy でアバターのルートを右クリック
2. `HoriCraft` → `TexSlim を追加 (Add TexSlim)`
3. Inspector の **かんたん** タブで現在のサイズを確認し、`圧縮を実行` を押す

初期設定のまま押して問題ありません。細かく詰めたい場合は **詳細** タブでテクスチャ1枚ずつ設定できます。

## 圧縮モード

| モード | 内容 | ダウンロードサイズ | テクスチャメモリ |
|---|---|---|---|
| 解像度＋Crunch（初期値） | 解像度を下げて Crunch 圧縮もかける | 減る | 減る |
| Crunchのみ | 解像度はそのまま、保存形式だけ Crunch に | 減る | 変わらない |
| 解像度のみ | 解像度だけ下げる（Crunch なし） | あまり減らない | 減る |

Crunch はゲーム中に展開されるため、テクスチャメモリ（VRAM）は減りません。
迷ったら初期値の「解像度＋Crunch」のままで大丈夫です。

## 知っておいてほしいこと

- **同じテクスチャを使う他のアバターにも反映されます。** テクスチャそのものの設定を変えるためです。
  利点でもありますが、知らないと驚きます。
- **Ctrl+Z では戻りません。** アセットのインポート設定変更は Unity の Undo の対象外です。
  ツール内の `↩ 元に戻す` を使ってください。
- **NormalMap には Crunch をかけません。** 法線が破綻するためです。解像度だけ下がります。
- コンポーネントは `VRC.SDKBase.IEditorOnly` を実装しているので、
  **アップロードしたアバターには残りません**（VRChat SDK がビルド時に自動で取り除きます）。
- VRChat SDK が入っていないプロジェクトでも動きます（その場合 `IEditorOnly` の分岐は無効になります）。

## 動作環境

- Unity 2022.3
- VRChat SDK は任意（あれば `IEditorOnly` が有効になります）
